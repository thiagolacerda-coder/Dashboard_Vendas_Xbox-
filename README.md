# 🎮 Xbox Game Pass Subscription Dashboard (Excel)

## 📊 Visão Geral

Este projeto consiste na criação de um **Dashboard interativo no Microsoft Excel** com foco na análise de assinaturas do **Xbox Game Pass**, incluindo diferentes produtos como:

- EA Play Season Pass
- Minecraft Season Pass
- Assinaturas gerais do Xbox Game Pass

O objetivo principal foi transformar dados brutos em **informações visuais claras, interativas e estratégicas**, facilitando a tomada de decisão.

---

## 🧱 Estrutura do Projeto

O projeto foi organizado em etapas fundamentais de construção de dashboards:

### 1. 📁 Entendendo a Base de Dados
- Análise inicial dos dados de assinaturas
- Identificação de colunas relevantes (tipo de plano, valores, status, etc.)
- Preparação dos dados para uso no dashboard

---

### 2. 🔄 Transformando Dados em Informações
- Criação de métricas principais (KPIs)
- Cálculo de totais de assinaturas
- Consolidação de dados para visualização

---

### 3. 👁️ Importância do Data View
- Utilização de tabelas organizadas
- Padronização de dados para evitar inconsistências
- Preparação para uso em gráficos e segmentações

---

### 4. 📈 Gráficos Dinâmicos e Filtros Visuais
- Implementação de gráficos interativos
- Uso de filtros como:
  - Plano: Anual, Mensal, Trimestral
- Segmentação visual para facilitar análise rápida

---

### 5. 🎨 Organização e Estilização do Dashboard

#### Layout
- Estrutura limpa e moderna
- Separação por blocos de informação

#### Elementos Visuais
- Cards de indicadores (KPIs)
- Gráfico de barras para comparação
- Logos e ícones personalizados

---

## 🎯 Principais Indicadores (KPIs)

O dashboard apresenta métricas importantes como:

- 💰 **Total EA Play Season Pass**: R$ 600,00  
- 💰 **Total Minecraft Season Pass**: R$ 940,00  
- 💰 **Total Geral Xbox Game Pass**: R$ 1.537,00

## 📊 Análises Disponíveis

- Análise por tipo de plano (Anual, Mensal, Trimestral)
